# market-opportunity-checker

A decision-support tool for small e-commerce sellers to evaluate whether a product category is worth testing.

## What it does
This project combines signals such as trend, competition, pricing, and customer pain points into a structured opportunity brief.

## Goal
Help small sellers make faster product and market validation decisions.

## Current status
MVP in progress.

## Planned features
- Input a product category or keyword
- Aggregate market signals
- Generate a structured opportunity report
- Output a simple verdict

## Tech stack
- Next.js
- TypeScript
- Python
- LLM API
